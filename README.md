## Hey, I'm Hanan.

I'm a student developer from Indonesia. I build web applications, experiment with ideas, and use AI to help me manage the development process.

I'm especially interested in **AI-assisted development**: writing better prompts, organizing project requirements, managing context, debugging problems, and turning ideas into working products.

I don't want AI to simply write code for me. I want to know how to guide the process and get a result that actually works.

- Currently learning and building with web technologies.
- Exploring mobile development with Flutter.
- Using AI as a development partner for planning, implementation, and debugging.
- Interested in software, business, and real estate investment.
