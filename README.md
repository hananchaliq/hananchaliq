## `01` / ABOUT ME

I'm a student developer from Indonesia exploring the intersection of **software development, AI-assisted workflows, and practical problem-solving.**

I don't just use AI to generate code. I use it to help structure projects, break down complex requirements, explore architecture, investigate bugs, and iterate toward a working product.

My focus is building useful digital products while continuously improving how I plan, develop, review, and maintain software.

- **Primary focus:** AI-assisted software development and project management.
- **Building with:** Web applications, interactive tools, and mobile apps.
- **Approach:** Plan the system, manage the context, review the output, and test the result.
- **Long-term direction:** Become a software developer who understands both technology and the problems it solves.

> **My philosophy:** AI can accelerate the work. Understanding the result is still my responsibility.
