| Layer | Responsibility |
|:---|:---|
| **Planning** | Translate ideas into specifications, feature lists, and implementation stages. |
| **Context engineering** | Organize project rules, architecture, constraints, and relevant documentation for AI-assisted work. |
| **AI-assisted implementation** | Use AI to explore solutions, generate implementations, and accelerate repetitive tasks. |
| **Debugging & validation** | Investigate errors, evaluate proposed fixes, and test whether changes actually work. |
| **Project continuity** | Preserve existing functionality, track unfinished work, and keep implementation aligned with requirements. |

> **Operating principle:** Generate with AI. Understand the result. Verify before shipping.

My goal is to make AI-assisted development more systematic, repeatable, and useful, rather than treating every prompt as an isolated coding session.
